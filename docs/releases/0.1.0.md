# agent-msg 0.1.0

Initial alpha release for local communication between Claude Code and Codex.

- Discover running sessions and address a peer by exact name or thread ID.
- Deliver through native harness transports, including steering a busy Codex session.
- Record message envelopes, delivery events, replies, and observed process metadata
  in SQLite. Reply routes use `agent-msg` message IDs.
- Inspect conversations in a read-only loopback web UI; `agent-msg ui` opens the browser.
- Install a self-contained plugin in either harness, or use the Python CLI.
  Requires Python 3.10+; no Python runtime dependencies. MIT license.

## Install

```sh
claude plugin marketplace add nsssayom/agent-msg
claude plugin install agent-msg@agent-msg

codex plugin marketplace add nsssayom/agent-msg
codex plugin add agent-msg@agent-msg
```

For the terminal command:

```sh
uv tool install https://github.com/nsssayom/agent-msg/releases/download/v0.1.0/agent_msg-0.1.0-py3-none-any.whl
agent-msg ui
```

In running Claude Code sessions, type `/reload-plugins` after installation.
For Codex, inspect `/plugins`; restart and resume if the skill is unavailable.
See the [README](https://github.com/nsssayom/agent-msg#install) for details.

## Validation and limits

49 offline tests passed; four live tests were skipped by default. Fresh wheel
installation, plugin export, and isolated local marketplace installs were checked
for both harnesses. Prior live tests on macOS covered both directions, correlated
replies, and a busy Codex peer. Harness versions: Claude Code 2.1.286, Codex CLI
0.159.0, daemon 0.159.2.

Linux live delivery and restricted sandbox configurations are not validated.
Internal harness protocols can change. `sent` is transport acceptance, not proof
of reading. Identity observations are audit data, not cryptographic authentication.
Messages are stored locally and may also enter the receiving harness's model
provider and transcript. See [data handling](https://github.com/nsssayom/agent-msg/blob/main/PRIVACY.md).

The GitHub marketplace is independently hosted. This release is not a claim of
approval or listing in either vendor's official directory. No PyPI publication.
